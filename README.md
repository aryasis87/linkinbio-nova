# Nova Ardhana — Links

Link in bio creative technologist Nova Ardhana: semua karya, tulisan, dan kontak dalam satu tempat.

**Demo live:** https://linkinbio-nova.vercel.app

![Tangkapan layar Nova Ardhana](public/og.jpg)

> Template link-in-bio dengan persona fiktif.

## Konsep

Persona Nova Ardhana, creative technologist. Aurora gelap dengan kaca buram, avatar bercincin, baris tautan bernomor, dan trio statistik.

## Halaman

`/`

## Teknologi

- Next.js 15.5 (App Router) dan React 19
- Tailwind CSS v4
- JavaScript
- Lucide (ikon)
- Font: Sora, Inter (next/font)
- SEO: metadata per halaman, Open Graph, JSON-LD, sitemap.xml, dan robots.txt

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000. Untuk build produksi: `npm run build` lalu `npm start`.
